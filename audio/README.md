# Drop the audio here

Put the beat in this folder (`.mp3`, `.wav`, `.m4a`, `.flac`, `.ogg`) and it
gets analysed into an editable MIDI file and a chord/notes PDF:

```bash
python3 beatkit/run.py audio/yourbeat.mp3
```

Output lands in `output/` — see `beatkit/README.md`.

Uploading from a browser: open the repo, go to this `audio` folder, then
**Add file → Upload files**, drag the track in, and commit.
